# Third-party notices

Our source is MIT-licensed. Upstream dependencies and weights retain their licenses. Installed Python distributions and container OS packages include separate upstream notices. Preserve them when distributing environments.

- pdfplumber / pdfminer.six: MIT. https://github.com/jsvine/pdfplumber and https://github.com/pdfminer/pdfminer.six
- pypdfium2: Apache-2.0/BSD-3-Clause, plus PDFium/dependency notices. https://github.com/pypdfium2-team/pypdfium2
- Tesseract: Apache-2.0; Leptonica/language data retain notices. https://github.com/tesseract-ocr/tesseract
- FastAPI, SQLAlchemy, Alembic, React, Vite: retain upstream package licenses/notices.
- PostgreSQL and pgvector: upstream PostgreSQL-style licenses.
- scikit-learn: BSD-3-Clause; numerical dependencies have separate notices.
- Ollama and model weights have separate licenses. Verify the actual installed artifacts with `ollama show --license MODEL` before redistributing. Weights are excluded from this repository.

Exact dependency identities are in `requirements.lock` and `frontend/package-lock.json`. No third-party invoice dataset is redistributed. Synthetic fixtures are generated by this project.
